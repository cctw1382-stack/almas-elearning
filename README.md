# منصة الماس للتعليم الإلكتروني | Almas E-Learning

منصة تعليمية عربية RTL تدعم أدوار **الطالب والمعلم وولي الأمر والإدارة**. بدأ تنفيذ المرحلة الأولى كنموذج تفاعلي مستقل في ملف HTML واحد ببيانات تجريبية.

## تجربة المرحلة الأولى
- [فتح ملف النموذج الأولي في المستودع](prototype/index.html) ثم تنزيله وفتحه بالمتصفح.
- لا يحتاج إلى خادم أو قاعدة بيانات أو اتصال إنترنت بعد تنزيله.
- يمكن تجربة تبديل الأدوار، تصفح المواد والدروس، البحث، الفيديو المحاكى بأسئلة توقف، الاختبار وتصحيحه، النتائج، الرسائل، الإشعارات والوضع الليلي.
- **تنبيه:** ليست مصادقة حقيقية، وليست منصة إنتاجية؛ بعض الأقسام ما زالت واجهات محاكاة.

## التقنية المقترحة لاحقاً
TypeScript/PWA للواجهة، Go API، PostgreSQL للإنتاج، Object Storage للفيديو. الهدف الأول 1,000 مستخدم متزامن ثم 10,000 بعد اختبارات حمل وتوسعة موثقة. SQLite للاختبار المحلي فقط.

## النشر
يمكن نشر النموذج الحالي على GitHub Pages إذا سمحت إعدادات المستودع والخطة، أو فتح `prototype/index.html` محلياً. لا تضع أسراراً أو بيانات حقيقية داخل الملف.
