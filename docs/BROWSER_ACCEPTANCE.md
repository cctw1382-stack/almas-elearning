## التشغيل القابل للإعادة

```sh
npm start
```

ثم افتح `http://127.0.0.1:4173/`. الخادم للمعاينة فقط، يقدّم ملف الواجهة المحدد دون فهرسة المجلدات أو API. تحقق التنفيذ من GET/HEAD للواجهة (200)، ومنع قراءة package.json (404)، ورفض POST (405). يمكن فتح HTML مباشرة دون Node أو إنترنت.

أداة `@axe-core/playwright@4.14.0` مرخّصة MPL-2.0 ومحصورة في اعتماد الاختبارات؛ لا تُضمّن في المنتج.
