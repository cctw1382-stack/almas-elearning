# النسخ الاحتياطي والاستعادة
1. PostgreSQL: نسخ أساسية دورية وWAL archiving من أجل PITR، وpg_dump -Fc كنسخة منطقية إضافية.
2. تشفير النسخ وتخزينها خارج الخادم وفي نطاق صلاحيات مستقل؛ احتفظ بنسخ ملفات الفيديو والمرفقات والإعدادات وإصدارات التطبيق.
3. اختبر الاستعادة شهرياً على staging، وتحقق من checksums وسلامة البيانات.
4. للانتقال: جهّز خادماً جديداً وإصدارات مطابقة، استعد قاعدة البيانات والملفات، نفّذ smoke tests واختبار حمل، ثم بدّل DNS بعد مزامنة آخر التغييرات وخطة رجوع.
5. أهداف استرشادية RPO 15 دقيقة وRTO 4 ساعات، لا تعتبر محققة حتى يثبتها اختبار استعادة.
