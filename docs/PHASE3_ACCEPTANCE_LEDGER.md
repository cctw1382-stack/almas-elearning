# المرحلة الثالثة — عقد التعلم والهوية — 2026-11-09

المرحلة النشطة: **الثالثة، partial**. أجاز المستخدم صراحة ترحيل اختبار الهاتف والمتابعة. الثانية تبقى جزئية، واختبار Android للتثبيت والفيديو بعد إصلاح المنتصف ما يزال blocked (قائمة ADB فارغة عند الاستئناف). هذه دفعة عقد API، لا خادم إنتاجي.

## المنجز في هذه الدفعة

`contracts/learning.openapi.json` مسودة OpenAPI 3.1 مستقلة عن موصل السجلات التطويري. تغطي ست عمليات: الجلسة، أسئلة اختبار الطالب، بدء المحاولة، قراءتها، حفظ إجابة، وتسليم المحاولة. لا تغيير في تطبيق الويب أو مخزن `almas-demo-v1` أو النموذج المرجعي.

الهوية من Keycloak، وعضوية المدرسة والصلاحيات من قاعدة التطبيق عند كل طلب. جميع موارد التعلم تحت مسار المدرسة؛ تغيير `schoolId` لا يمنح العضوية. المحاولات مملوكة للطالب المحقق، وتُرد الموارد غير المملوكة أو العابرة للمدارس بـ404. ولي الأمر والمعلم لا يستخدمان مسار الكتابة باسم الطالب؛ واجهاتهما المقيدة تأتي في عقود لاحقة.

أسئلة الطالب وأنواع الاستجابات مغلقة، دون `correct` أو مفتاح إجابات أو شرح يكشف الإجابة. يحدد الخادم موعد الانتهاء والتصحيح، وتستخدم الإجابات معرف الخيار بدلاً من موقعه في المصفوفة. المحاولة النشطة لا تحمل درجة، والنتيجة المقدمة مستقلة وغير قابلة للاستبدال.

كتابة الإجابة مشروطة بـ`expectedRevision` و`Idempotency-Key`. على التنفيذ ربط مفتاح الإعادة بالهوية والمدرسة والعملية والمورد وبصمة الطلب، وتخزين النتيجة مع الكتابة في معاملة واحدة لمدة 24 ساعة على الأقل. يُعاد فحص الصلاحية قبل إعادة النتيجة. يُفحص سجل الإعادة قبل مقارنة revision؛ الطلب المكرر نفسه يعيد النتيجة الأصلية، واستخدام المفتاح نفسه لبيانات مختلفة يعطي 409. المفتاح المنتهي لا يتجاوز موعد المحاولة أو حالتها. لا إعادة محاولة كتابة عمياء في المتصفح.

نتائج الأوامر النهائية لهذه الدفعة: `npm run test:contracts` = 4/4، دون تخطٍ أو فشل (`.work/phase3-contract-final.log`)؛ `npm run test:web:unit` = 30/30 (`.work/phase3-baseline-unit.log`)؛ `npm run build:web` = نجاح البناء وفحص الأنواع (`.work/phase3-baseline-build.log`). بقيت نسخة SW `a7af085456ae5e1b282b7c9f` وJS `index-l4m1Kwi7.js` كما في دفعة القبول السابقة. لم تُعد مصفوفة المتصفحات لأن هذه الدفعة لم تغير الواجهة أو البناء الناتج؛ نتائج 167 ناجحاً وحالة متخطاة تخص التشغيل السابق المسجل في سجل الثانية. أدوات Go وDocker وpsql لم تظهر في PATH عند الاستئناف؛ يلزم تجهيز بيئة التنفيذ بعد العقد والتصميم، ولا يوجد خادم ضمن نتيجة اختبارات المخطط.

## التسلسل التالي وبوابة الإغلاق

1. توليد أنواع TS من العقد، وتحديد توليد Go والتحقق من مدخلات ومخرجات HTTP؛ يبقى المستودع المحلي مرجعاً ولا يُرحّل تقدم المستخدم إلى UUID تلقائياً.
2. استكمال تصميم PostgreSQL: هوية `(issuer, subject)` منفصلة عن عضوية المدرسة، مفاتيح وعلاقات مركبة مع `school_id`، تسجيل الطلاب وربط ولي الأمر والموافقات والحضور والجلسات وحالات الفيديو. مفاتيح التصحيح ونسخة الاختبار المجمدة غير مكشوفتين للطالب. بعدها migrations واختبارات عزل وRLS واستعادة على بيانات وهمية.
3. Go modular monolith مع تحقق OIDC الفعلي من signature/issuer/audience/expiry، ثم ربط دخول الواجهة دون تخزين رموز الدخول في localStorage. إعداد جمهور API وعنوان الرجوع في Keycloak مطلوبان؛ لا يكفي ظهور صفحة دخوله.
4. تنفيذ دورة الاختبار واختبار التزامن: إرسالان بالـrevision نفسه، إعادة بدء محاولة بمفتاح جديد، مهلة منتهية، انقطاع ثم إعادة الطلب نفسه، إلغاء عضوية بين الطلب والإعادة، ومدرسة أخرى ومعرف سؤال أو خيار غير تابع. موعد الخادم هو المرجع.
5. مراجعة بشرية لتغييرات auth/permissions/schema ونسخ احتياطي واستعادة وخطة رجوع وفق SPECKIT قبل الدمج أو اعتماد المرحلة. العقود الآن مسودة قابلة للمراجعة ولا تمثل موافقة أمنية أو سعة إنتاجية.

## دفعة توليد الأنواع — 2026-11-09

أضيف `scripts/generate-learning-types.mjs` و`contracts/generated/learning.d.ts`. العقد هو المصدر الوحيد لهذه الأنواع؛ لا تعديل يدوي للملف المولد. يتضمن الملف بصمة SHA256 لمحتوى العقد، ولا يحتوي بيانات مستخدمين أو توقيت توليد متغيراً. يقبل المولد المراجع الداخلية فقط، ويتحقق من صحة العقد قبل كتابة أي مخرجات. وضع الفحص لا يكتب ملفات ولا يصلح التقادم تلقائياً كي لا يخفيه في CI. مقارنة المخرجات تتجاهل فرق CRLF/LF فقط.

أضيف `check:contracts` إلى workflow بعد اختبارات العقد؛ تشغيل GitHub ما يزال not run. المولد أداة تطوير فقط، بإصدار مقفل وintegrity من سجل npm الرسمي ورخصة MIT محفوظة في `docs/licenses/openapi-typescript-MIT.txt`. سجل التثبيت `.work/phase3-types-install.log`، وفحص npm audit الحالي `.work/phase3-types-audit.json` أعاد صفر تنبيهات معروفة، لا ضمان خلو من الأخطاء. التوثيق الأصلي: [Node API للمولد](https://openapi-ts.dev/node).

[مصدر Audience Mapper](https://github.com/keycloak/keycloak/blob/26.8.1/services/src/main/java/org/keycloak/protocol/oidc/mappers/AudienceProtocolMapper.java).
