# الأمان والخصوصية
- مصادقة إنتاجية عبر جلسات خادم أو OIDC، كلمات مرور مجزأة Argon2id، Cookies محمية HttpOnly/Secure/SameSite، TLS.
- صلاحيات RBAC وفحص ملكية الموارد وعزل بيانات المدارس على كل API endpoint، وليس في الواجهة فقط.
- حماية CSRF/XSS/SQL injection، التحقق من المدخلات، rate limiting، audit logs، فحص الملفات.
- لا مفاتيح AI أو دفع أو أسرار في الواجهة أو GitHub؛ استخدم secrets manager وCI secret scanning.
- بيانات الطلاب القاصرين: الحد الأدنى من الجمع، موافقة وربط ولي الأمر، سياسة احتفاظ وحذف وتصدير.
- الدفع الحقيقي عبر مزود رسمي وتحقق توقيع webhook وidempotency؛ لا تخزن PAN/CVV.
- الفيديو: روابط موقعة قصيرة الأجل؛ لا توجد حماية مطلقة من تصوير الشاشة.
