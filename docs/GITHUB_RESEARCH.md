# مشاريع GitHub المشابهة
- Moodle: https://github.com/moodle/moodle — LMS شامل ومرجع للميزات؛ يعتمد PHP.
- Moodle App: https://github.com/moodlehq/moodleapp — تجربة تطبيق جوال مرتبط بـMoodle.
- Kolibri: https://github.com/learningequality/kolibri — محتوى تعليمي وعمل محلي.
- Canvas LMS: https://github.com/instructure/canvas-lms — إدارة مقررات واختبارات؛ تشغيل كبير.
- Open edX: https://github.com/openedx/openedx-platform — دورات تفاعلية؛ تشغيل معقد.
**تنبيه:** توافق الشاشات الذكية وأجهزة Android TV يتطلب اختبار المتصفح والتحكم عن بعد عملياً؛ دعم الويب لا يعني تطبيقاً أصلياً. تحقق من LICENSE/NOTICE والإصدارات والاعتمادات قبل نسخ أي كود.
**القرار:** اعتماد هذه المشاريع كمراجع UX ووظائف، وبناء منصة الماس بشكل أخف، مع إمكانية إعادة تقييم Moodle إذا كان إطلاق LMS جاهز أولوية.
