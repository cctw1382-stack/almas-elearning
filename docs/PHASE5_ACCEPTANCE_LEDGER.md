# قبول P5 في المحاكاة المحلية

| المعيار | الدليل |
| --- | --- |
| اشتراك Sandbox | `TestBilling` يثبت رفض التوقيع المفقود، وتطبيق حدث واحد عند عشر عمليات إرسال، وحجب الوصول في pending وfailed وسحبه عند refunded. الحقول محصورة بمعرّف الحدث والطلب والحالة. |
| AiProvider | `TestAI` يثبت حد الطلبات والتكلفة وعزل السجل وتسجيل الفشل ومنع إرسال بيانات القاصرين والنص غير المسموح. |
| قياس الحمل | `node scripts/load-local.mjs 8 10` خرج 0. أرسل 560 طلباً عبر سيناريو دخول ودرس وتقدم وبدء امتحان وتسليم وقائمة HLS ومقطع. |

قياس أولي على محاكي HTTP داخل عملية Node واحدة. النتيجة p50 ‏3.52 ms، وp95 ‏7.43 ms، وp99 ‏24.02 ms. أخطاء 4xx و5xx والاتصال كلها صفر.

جهاز الاختبار Windows ‏10.0.26300، ومعالج Intel Core i5-1145G7، و8 معالجات منطقية، وذاكرة 7.6 GiB، وNode ‏22.23.2. لا يقيس المحاكي أداء Keycloak أو PostgreSQL أو Go أو فك ترميز HLS. قياس 1,000 أو 10,000 متزامن يحتاج بنية واختباراً منفصلين.

تعمل الاشتراكات وسجل AI في الذاكرة. حساب مزود الدفع ومفاتيح AI وخادم اختبار السعة ضمن `needs-owner`. [PR #9](https://github.com/cctw1382-stack/almas-elearning/pull/9).
