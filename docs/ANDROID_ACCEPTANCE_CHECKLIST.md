# قبول منصة الماس على Android

من جذر المستودع، افتح PowerShell على الحاسوب. شغّل الأمر على الشبكة المنزلية فقط بعد إذن المالك. يستخدم الاختبار بيانات Mock.

```powershell
npm --prefix apps/web run build
if ($LASTEXITCODE -ne 0) { throw 'فشل البناء' }
ipconfig
npm --prefix apps/web run preview -- --host 0.0.0.0 --port 4174
```

صل الهاتف بالشبكة نفسها وافتح `http://<IPv4-للحاسوب>:4174/` باستخدام عنوان IPv4 لمحول Wi-Fi النشط من `ipconfig`. أبقِ الطرفية مفتوحة أثناء الفحص ثم أوقف المعاينة بـ`Ctrl+C`. HTTP على عنوان الشبكة يكفي لفحص الواجهة. قبول تثبيت PWA والعمل دون اتصال يتطلب سياقاً آمناً مثل HTTPS.

| الفحص على الهاتف | معيار النجاح | النتيجة والملاحظات |

| الدخول التجريبي | أدخل اسماً وهمياً وتأكد من ظهور لوحة الطالب وإمكانية تبديل الدور. | |
| الدرس والفيديو | افتح درساً واختر مقطعاً قصيراً بصوت. شغّله من البداية حتى النهاية وتأكد بالاستماع من استمرار الصوت، خصوصاً بعد المنتصف. | |
| الامتحان | ابدأ اختباراً وأجب عن سؤال. حدّث الصفحة وتحقق من بقاء الإجابة، ثم سلّم واعرض النتيجة. | |

| الوضع الداكن | فعّل المظهر الداكن وتنقّل بين الدرس والاختبار. افحص وضوح النص والأزرار. | |

اكتب لكل بند «نجح» أو «فشل» أو «لم يُختبر». عند الفشل سجّل الدور والصفحة والخطوة والنتيجة التي ظهرت.
