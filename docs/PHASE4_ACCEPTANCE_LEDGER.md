# قبول P4 المحلي

| المعيار | الدليل |
| --- | --- |
| رفع المعلم المالك وعزل المدارس | نجحت اختبارات HTTP على PostgreSQL الأصلي والمستعاد. عاد 201 للمالك و404 للطالب والمعلم من مدرسة أخرى. |
| تحويل الفيديو | نجح `TestPublishHLS` مع ffmpeg المحلي. حُفظت المقاطع قبل القائمة وسُجّل أصل المشاهدة بعد اكتمال التخزين. |
| روابط مشاهدة محددة الصلاحية | نجحت اختبارات HTTP للتوقيع والهوية وعزل المدرسة ورفض الرابط المنتهي. |
| مشاهدة الطالب وتقدم المشاهدة | نجح Chromium أمام Keycloak وGo وPostgreSQL وتخزين محلي. رفع MP4، وطلب مقطع HLS، واستعاد الموضع بعد Refresh، ورُفض الرابط المنتهي. |
| قاعدة البيانات والامتحانات | نجحت اختبارات العزل والتسليم وانتهاء المحاولة في القاعدة الأصلية وبعد الاستعادة. نجحت دورة امتحان الطالب في Chromium. |

شُغّل `infra/test-postgres-memberships.ps1` مع Keycloak المحلي و`ALMAS_TEST_BROWSER=1` و`ALMAS_TEST_FFMPEG`، وكانت النتيجة خروج 0. سجل التنفيذ `.work/p4-hls-browser-verified.log`. المشغّل يضم `hls.js 1.7.3` من قفل الحزم.

تبقى إعدادات Compose والتخزين الفعلي وCDN وإدارة إعادة المحاولة في بنية الإنتاج خارج دليل التشغيل المحلي الحالي. التخزين وCDN ضمن `needs-owner`.
