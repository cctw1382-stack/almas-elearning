# دفعة فصل البيانات — 2026-11-05

آخر دفعة: فُصل عرض الترحيب والحساب التجريبي وبطاقات المواد والأصول المتجهة إلى `apps/web/src/views/public-pages.js` بحقن صريح للاعتمادات. تبقى معالجة الأحداث في المتحكم الحالي. نجح البناء والفحص الصارم و23 اختبار Chromium للدخول واستكشاف المواد وإدارة السجلات ووصولية الصفحات العامة في المظهرين. الأدلة: `.work/public-views-final.log`. هذا فصل جزئي للعرض؛ بقية الصفحات والأحداث وعقد API وقبول Android ما تزال مفتوحة.

فُصل MockRepository في src/mock-repository.js، وربطت الواجهة به عبر src/repository.ts الذي يعرّف عقداً عاماً للقراءة والتعديل وحالة الدروس ومحاولات الاختبار. يطابق التنفيذ العقد عند البناء دون تحويل قسري للنوع. يستمر التحقق من البيانات وقت التشغيل ومن إصدار التخزين almas-demo-v1.

نجح البناء وفحص الأنواع و40 اختبار بيانات، إضافة إلى أربعة اختبارات Chromium لمسارات التسجيل وإدارة المواد واستمرار المحاولة وتهريب HTML. اسم ملف JavaScript الناتج ونسخة الكاش مطابقان للبناء السابق، لذا لا يوجد تغيير في شكل التخزين أو سلوك التطبيق بسبب هذا الفصل.

هذه دفعة فصل وعقد TypeScript. ما يزال تنفيذ MockRepository نفسه JavaScript، مع بقاء تحويل تفاصيله وأنواع كل مجموعة إلى TypeScript عملاً تالياً. عقد الشبكة سيكون غير متزامن ويحتاج تصميم OpenAPI قبل ربط خادم حقيقي. تبقى إعادة مصفوفة المتصفحات الكاملة وقبول Android الفعلي ضمن إغلاق المرحلة.
## استئناف التحقق — 2026-11-06

اكتملت تغطية مصفوفة الواجهة عبر تشغيلين على البناء نفسه. نجح 102 فحص Chromium وFirefox قبل توقف التشغيل الأول، ثم نجح 65 فحص WebKit وأحجام الشاشة وتُخطّي فحص فيديو WebKit الأصلي على Windows. المجموع 167 ناجحاً من 168 حالة، دون إخفاق مسجل. يظل نقل التنفيذ الداخلي للمستودع إلى TypeScript وقبول Android الفعلي مفتوحين.

شُغّل Keycloak 26.8.1 محلياً لنطاق almas-local. تحققت أداة التحقق من تعريف OIDC وظهور صفحة الدخول لطلب PKCE صحيح، ورفض عنوان رجوع آخر، ورفض طلب بلا PKCE. يمكن إعادة التشغيل والفحص وفق [دليل الهوية المحلية](../infra/identity/README.md). ما زال اتصال واجهة الماس بخادم Go وPostgreSQL وعزل المدارس ضمن العمل المتبقي من المرحلة الثالثة.

## فصل التحقق وقواعد الدروس — 2026-11-07

تتضمن النسخة الآن وحدات TypeScript فعلية للتخزين المحلي وإنشاء وتصحيح محاولات الاختبار (التغييران السابقان 0ba1949 وdd68c1d)، ثم التحقق من JSON والمفاتيح والأرقام والنصوص والسجلات والأسئلة وروابط الطلاب والمواد، والتحقق من تقدم الدروس ودمج تعديلاته. بقيت صيغة almas-demo-v1 كما هي، ولم يتغير ملف النموذج المرجعي.

قرار التنفيذ: استخراج قواعد التحقق الحالية مع رسائلها وحدودها بدلاً من تغيير مخطط البيانات أثناء نقل اللغة؛ يقلل ذلك خطر فقد البيانات المحفوظة. يبدأ اختبار الوحدة الجديدة بالفشل لغيابها ثم ينجح بعد تنفيذها. تشمل الحالات البيانات الدائرية، عمق JSON، المفاتيح غير الآمنة، الخيارات غير الصالحة، تكرار الطلاب والأسئلة، والروابط إلى سجلات مفقودة.

نجح 25 اختباراً للنسخة الجديدة و20 للمرجع؛ هذه مجموعتان منفصلتان، وليستا 45 اختباراً مختلفاً للمستودع الجديد. نجح فحص الأنواع، وأُعيد تشغيل Keycloak المحلي والتحقق من issuer وPKCE وقائمة عناوين الرجوع. تشغيله لا يعني اكتمال تسجيل الدخول داخل المنصة.

المتبقي من المرحلة الثانية: إتمام أنواع وعمليات المستودع المتبقية، عقد الشبكة وAPI adapter، فصل العرض والأحداث، وقبول تثبيت Android الفعلي. المرحلة الثالثة ما تزال تحتاج API وPostgreSQL وتكامل الدخول والصلاحيات وعزل المدارس. لا يُعلن إغلاق أي من المرحلتين بهذه الدفعة.

نتائج التحقق: نجحت المصفوفة الكاملة بعد نقل JSON وتقدم الدروس: 167 فحصاً مع تخطي فيديو WebKit الأصلي على Windows. بعد إضافة نقل قواعد السجلات، نجح البناء وفحص الأنواع و24 فحص Chromium لإدارة السجلات والاختبارات والفيديو، ثم خمسة فحوص PWA للتحديث والعمل دون اتصال. لا تُنسب المصفوفة الكاملة إلى البناء الأخير؛ الأخير له الفحوص المركزة المذكورة. السجلات المحلية في `.work/verification-nov7-*.log`.

شُغّلت المعاينة النهائية على http://127.0.0.1:4175/ وتحقق HTTP 200 للصفحة وملف JavaScript الجديد. اختير منفذ مستقل بعد رفض سياسة التنفيذ أمر إعادة تشغيل خدمة 4174؛ لم تُوقف الخدمة القديمة. بيانات المتصفح مرتبطة بالمنفذ، لذلك لا تظهر بيانات 4174 تلقائياً على 4175.

## إكمال نقل المستودع إلى TypeScript — 2026-11-07

اكتمل تحويل `mock-repository.ts`، بما فيه CRUD والسجل التدقيقي والإعدادات وحالة الدروس والمحاولات والتحقق من التخزين. يطبّق `Repository` مباشرة؛ لا يستخدم تعطيل فحص الأنواع أو تحويل `as` لتجاوز المدقق. يعيد `LocalPersistence.load<T>` البيانات بعد تحقق يثبت نوعها وقت التشغيل. بقي مفتاح التخزين وإصداره دون تغيير.

أصبحت اختبارات العقد تجرّد أنواع المصدر الفعلي بأداة Node قبل تشغيله في بيئة الساعة والتخزين المعزولة. فشلت أولاً عند طلب ملف TypeScript غير الموجود، ثم نجح 26 اختباراً بعد التحويل. أضيف اختبار يفتح جميع مجموعات النسخة السابقة وإعداداتها وملاحظات الطالب والمعلم دون إعادة كتابة التخزين، ثم يتأكد أن النسخة السابقة تقرأ تعديلات النسخة الجديدة. نجح البناء والفحص الصارم و31 اختبار Chromium لمسارات السجلات والتواصل والاختبارات والفيديو.

راجعت جهة مستقلة تغييرات هذه الدفعة قراءةً ولم تجد ملاحظة مانعة. النسخ العام بـJSON يبقى داخلياً لبيانات JSON التي تحققت صحتها؛ لا يعاد استخدامه لنسخ كائنات أو أنواع أخرى.

حالة الخطة الحالية: أُغلق نقل المستودع إلى TypeScript. ما يزال API adapter والعقد غير المتزامن وفصل العرض والأحداث وقبول Android ضمن المرحلة الثانية، وتكامل الخادم وقاعدة البيانات والدخول ضمن الثالثة.

التحقق النهائي لهذه الدفعة: 9 فحوص Firefox/WebKit ناجحة مع تخطي الفيديو الأصلي في WebKit على Windows، و5 فحوص PWA ناجحة. إجمالي الواجهة 40 ناجحاً مع حالة واحدة متخطاة، إضافة إلى 26 اختبار بيانات. المعاينة http://127.0.0.1:4176/ استجابت بالرمز 200 للصفحة وملف JavaScript. المنفذ الجديد له مساحة تخزين مستقلة في المتصفح. الأدلة في `.work/full-ts-*.log`؛ لم تُعد المصفوفة الكاملة لأن نطاق التغيير طبقة البيانات، وغُطيت مساراتها مباشرة.
