# دفعة فصل البيانات — 2026-11-05

فُصل MockRepository في src/mock-repository.js، وربطت الواجهة به عبر src/repository.ts الذي يعرّف عقداً عاماً للقراءة والتعديل وحالة الدروس ومحاولات الاختبار. يطابق التنفيذ العقد عند البناء دون تحويل قسري للنوع. يستمر التحقق من البيانات وقت التشغيل ومن إصدار التخزين almas-demo-v1.

نجح البناء وفحص الأنواع و40 اختبار بيانات، إضافة إلى أربعة اختبارات Chromium لمسارات التسجيل وإدارة المواد واستمرار المحاولة وتهريب HTML. اسم ملف JavaScript الناتج ونسخة الكاش مطابقان للبناء السابق، لذا لا يوجد تغيير في شكل التخزين أو سلوك التطبيق بسبب هذا الفصل.

هذه دفعة فصل وعقد TypeScript. ما يزال تنفيذ MockRepository نفسه JavaScript، مع بقاء تحويل تفاصيله وأنواع كل مجموعة إلى TypeScript عملاً تالياً. عقد الشبكة سيكون غير متزامن ويحتاج تصميم OpenAPI قبل ربط خادم حقيقي. تبقى إعادة مصفوفة المتصفحات الكاملة وقبول Android الفعلي ضمن إغلاق المرحلة.
