| AI | اعتماد المزوّد والميزانية وسياسة بيانات القاصرين وإتاحة الاعتماد عبر مدير الأسرار | وصل المزوّد واختبار الحدود والفشل وفصل السجلات |
| التخزين وCDN | اختيار مزوّدين وتوفير حاوية اختبار خاصة وتهيئة وصول محدود | اختبار الرفع والاستعادة وعزل المسارات وانتهاء الروابط |

| Android | إتاحة هاتف فعلي وتجربة تثبيت PWA والتحديث وتشغيل الفيديو حتى النهاية | تجهيز سيناريو قبول وتوثيق النتيجة وإصلاح العيوب القابلة للتكرار |
| التلفاز والريموت | تحديد طراز التلفاز وتجربة اتجاهات الريموت والاختيار والرجوع | تدقيق التنقل والتركيز وتسجيل حدود التوافق |
| الصوت | سماع فيديو الاختبار على الأجهزة المطلوبة وتأكيد الاستمرار حتى النهاية | إعادة اختبار المشغل وربط أي إخفاق بالجهاز والترميز |
| قارئ الشاشة | تحديد القارئ والجهاز وتجربة الدخول والتنقل والاختبار | تجهيز الحالات ومراجعة التسميات والتركيز وإعادة الاختبار |
| PR #1 وبقية الطلبات | مراجعة الفروق والبوابات وتحديد ترتيب الدمج، وإعطاء موافقة صريحة لكل دمج مطلوب | تحديث الفروع والتحقق من CI والتعارضات، ثم تنفيذ القرار المأذون به |

لا تُرسل مفاتيح أو بيانات حسابات في المحادثة. تبقى بيئة Compose المحلية أيضاً بحاجة إلى محرك Docker متاح وبيانات اختبار معزولة.
