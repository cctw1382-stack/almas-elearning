# خطة التنفيذ التالية — 2026-11-01

المستخدم أجاز بدء المرحلة التالية مع تقليل استهلاك الاستخدام. لا يمكن قراءة رصيده المتبقي مباشرة؛ تُقسم الأعمال إلى دفعات مكتملة صغيرة، بمراجعة مستقلة محدودة واحدة ودون إعادة اختبارات شاملة لكل تعديل توثيق. نطاق يوم 2026-11-02 وأدلته في [تسليم الدفعة](PHASE2_DAILY_DELIVERY.md).

## المرحلة الثانية: TypeScript / Vite / PWA

1. أساس بناء مستقل داخل apps/web، مع إبقاء prototype/index.html مرجعاً ثابتاً.
2. نقل MockRepository إلى TypeScript بواجهة Repository مشتركة؛ إضافة API adapter دون ربط إنتاجي. التحقق من توافق بيانات التخزين الحالية قبل أي تغيير.
3. فصل عرض الصفحات والأحداث تدريجياً مع الحفاظ على هوية الماس والأدوار الأربعة.
4. إضافة manifest وأيقونات وتخزين offline محدود بملفات التطبيق؛ لا تخزين ملفات الفيديو الخاصة أو استجابات الحسابات آلياً.
5. بوابة التسليم: build وtypecheck، الاختبارات الحالية على النسخة المبنية، اختبار تحديث service worker وعدم فقد البيانات، وتشغيل Android. استخدام Wi-Fi HTTP للمعاينة لا يثبت قابلية تثبيت PWA؛ يلزم HTTPS أو localhost للاختبار المناسب.
