# المعمارية المقترحة
**الآن:** `prototype/index.html` ملف مستقل يعمل في المتصفح ببيانات Mock. **الإنتاج:** Browser/PWA → HTTPS reverse proxy → Go modular monolith API → PostgreSQL. الفيديوهات والمرفقات في S3-compatible Object Storage مع روابط قصيرة العمر وCDN عند الحاجة.
Go اختيار للكفاءة وسهولة النشر، وليس ادعاء أنه الأسرع دائماً. Redis اختياري بعد قياس الحاجة؛ تجنب microservices وKubernetes في البداية.
التوسع من 1,000 إلى 10,000 متزامن يتطلب تعريف سيناريو الحمل، اختبارات API والبث، زيادة نسخ API خلف موازن، مراقبة أداء قاعدة البيانات والاتصالات، نقل الفيديو إلى تخزين وتوزيع مستقلين. لا يعني عدد المستخدمين عدد جلسات البث المتزامنة.
النقل بين الخوادم يعتمد على حاويات بإصدارات ثابتة، config/secrets منفصلة، قاعدة بيانات مستعادة وملفات Object Storage ومراقبة DNS وخطة رجوع.
