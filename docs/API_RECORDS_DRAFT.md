# عقد نقل السجلات — مسودة المرحلة الثانية

التنفيذ: `apps/web/src/api-records.ts`. عقد غير متزامن مستقل عن المستودع المحلي، يحقن دالة النقل لتجربة الاستجابات دون خدمة حقيقية. الواجهة الحالية تستمر باستخدام المستودع المحلي؛ لم يُفعّل اتصال إنتاجي أو تسجيل دخول شبكي.

المسار الأساسي يمرر كعنوان URL، ثم تضاف المسارات التالية:

| العملية | الطلب | الاستجابة الناجحة |
| --- | --- | --- |
| list | GET records/{kind} | مصفوفة سجلات JSON |
| get | GET records/{kind}/{id} | سجل JSON؛ 404 يعيد null |
| save دون id | POST records/{kind} | السجل المحفوظ بمعرّفه |
| save مع id | PUT records/{kind}/{id} | السجل المحفوظ |
| remove | DELETE records/{kind}/{id} | نجاح HTTP يعيد true؛ 404 يعيد false |

السجل يحتوي `id` نصياً صالحاً و`name` نصياً؛ يسمح ببيانات JSON إضافية. التحقق هنا لبنية النقل الأساسية، وليس تحققاً كاملاً من قواعد كل مجموعة. الأخطاء الأخرى ترفض الوعد وتعرض رمز HTTP دون تمرير محتوى الخادم إلى HTML. الطلبات لا تُخزن في الكاش، ولا تُرسل بيانات اعتماد المتصفح تلقائياً، وترفض إعادة التوجيه وتنتهي مهلة الطلب بعد 15 ثانية. لا إعادة محاولة تلقائية للكتابة.

هذا نطاق أولي للسجلات فقط. لم يشمل بعد محاولات الاختبار وتقدم الدروس والإعدادات أو عقد OpenAPI الإنتاجي. قبل ربط المرحلة الثالثة يلزم تعريف الهوية والمدرسة والصلاحيات من الخادم، وترقيم الصفحات، والتزامن والتعارض، ومعرّفات منع تكرار الكتابة. لا يُعرض مفتاح الإجابات للطالب عبر العقد الإنتاجي.

الاختبارات الحالية تحقّق CRUD ومساراته وحالات 404 و500 وبنية الاستجابات والمفاتيح غير الصالحة وسياسة الطلب. هي اختبارات نقل محاكى، وليست إثبات تشغيل خادم API.
