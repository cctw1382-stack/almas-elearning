# اختبارات القبول
## نموذج HTML
- يعمل الملف دون خادم أو إنترنت.
- تنقل لكل الأدوار الأربعة وقوائمهم الرئيسية.
- تبديل الأدوار، البحث، اختيار عنصر وعرض تفاصيله، اختبار تجريبي ونتيجة، واجهة درس فيديو، الإشعارات.
- الوضع الليلي، RTL، حالات فارغة ورسائل خطأ، أزرار قابلة للوصول بلوحة المفاتيح.
- فحص عرض 360 و768 و1366 بكسل، وعدم وجود أخطاء JavaScript.
## الإنتاج
- اختبارات عزل الطلاب والمدارس وRBAC وIDOR، أمان API، استعادة النسخ، migrations.
- تحديد توزيع الطلبات والبث ثم اختبار 1,000 جلسة متزامنة بقياسات p95 وCPU/RAM/DB IO.
- إعادة الاختبارات قبل أي ادعاء بدعم 10,000 متزامن.
