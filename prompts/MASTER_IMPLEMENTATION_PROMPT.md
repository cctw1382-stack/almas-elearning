# برومبت التنفيذ الرئيسي — منصة الماس
أنت مهندس مسؤول عن تطوير منصة الماس. اقرأ `00_PROJECT_STRUCTURE.md` و`REQUIREMENTS.md` و`SPECKIT.md` وكل ملفات `docs/` قبل تعديل المشروع.
## المطلوب الآن
طوّر `prototype/index.html` فقط ليصبح نموذجاً تفاعلياً عربياً RTL متجاوباً من ملف HTML واحد يحوي CSS/JS/Mock Data، ويعمل دون خادم. يجب أن يغطي الطالب والمعلم وولي الأمر والإدارة، مع تنقل فعلي بين صفحاتهم، بحث وفلاتر، نماذج، مشغل درس تجريبي، اختبار محاكى، نتائج، تقدم، رسائل وإشعارات، حالات فارغة وخطأ، ووضع ليلي.
## قواعد التنفيذ
- اعزل الوصول للبيانات عبر MockProvider بواجهة مستقلة يمكن استبدالها لاحقاً بـ API Adapter.
- لا تستخدم أي مفتاح سري أو دفع أو تسجيل دخول حقيقي؛ وضح المحاكاة.
- اجعل جميع الأزرار تعمل أو تُظهر تنبيهاً واضحاً بأن الميزة مؤجلة.
- حافظ على RTL ووصولية التنقل بلوحة المفاتيح والتباين والأجهزة الصغيرة.
- نفذ اختبارات يدوية للشاشات 360/768/1366px ولكل دور، وبلّغ عن أي نقص.
## المراحل التالية
بعد موافقة مالك المشروع فقط: نقل الواجهة إلى TypeScript/PWA، بناء Go API وPostgreSQL migrations، تخزين الفيديو خارج خادم API، مصادقة وصلاحيات حقيقية، دفع وAI، ثم اختبار حمل 1K والتوسع نحو 10K.
## Vibe Coding
قبل كل تعديل: اقرأ السياق، حدد خطة، نفذ أصغر تعديل، اختبر، وثق، ولا تلمس الإنتاج أو بيانات حقيقية تلقائياً.
